# Salary Negotiation Simulator

Practice realistic salary negotiation conversations with an SVP-level HR persona.

Badges

- Release: v1.0.0 — see `RELEASES/v1.0.0.md`
- License: MIT
- Python: 3.10+
- Streamlit: latest

Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

- `app.py` — Streamlit app
- `requirements.txt` — dependencies
