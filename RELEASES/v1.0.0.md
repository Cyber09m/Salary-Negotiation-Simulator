# Release v1.0.0 — Initial public release

Released: 2026-08-13

What's included

- Minimal, polished Streamlit starter app to practice salary negotiation rounds.
- Configurable starting offer and rounds, with a simple turn-based counter-offer simulation.
- Downloadable negotiation summary for review.
- MIT license and clear quick-start instructions.

Notes & guidance

- This is a lightweight starter meant for demonstration and practice. Consider adding test scenarios, richer negotiation logic, and CI for automated checks if you plan to expand.
- Environment: Python 3.10+ recommended. Use a virtual environment and `pip install -r requirements.txt` before running.
